How does this work?

A Python script runs via GitHub Actions and scrapes 200+ Telegram channels for proxy and VPN configurations. Each config is tested with a real TCP connection to measure latency. Configs are deduplicated, ranked by trust score, and stored as JSON files on GitHub Pages. This page loads those JSON files and displays them — everything happens in your browser.

Ping values are measured from the GitHub Actions runner, not from your internet connection. They give you a reliable indication of server responsiveness.

No data is ever sent to any server. All processing happens locally in your browser.
