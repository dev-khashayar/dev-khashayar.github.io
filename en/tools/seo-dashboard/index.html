How to Export from Google Search Console

1. Open Google Search Console → Performance report
2. Set your desired date range (recommended: last 28 days)
3. Make sure Queries, Clicks, Impressions, CTR, and Position are selected
4. Click Export (top-right) → Google Sheets
5. In Google Sheets: File → Download → Microsoft Excel (.xlsx)
6. Upload the .xlsx file here
7. For multi-sheet analysis: export separate reports (Pages, Countries, Devices) as additional sheets in the same file

Your data is processed entirely in your browser. It is never uploaded to any server.
