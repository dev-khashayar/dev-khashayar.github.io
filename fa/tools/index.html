این ابزارها چطور کار می‌کنند؟

تمام ابزارهای این صفحه توسط GitHub Actions اجرا می‌شوند. بعضی از آن‌ها به صورت خودکار و زمان‌بندی‌شده اجرا می‌شوند و خروجی را در قالب JSON ذخیره می‌کنند. بعضی دیگر مثل یک فرم عمل می‌کنند — شما مقادیر را وارد می‌کنید، Action اجرا می‌شود و نتیجه به صورت زنده به شما نمایش داده می‌شود. بدون سرور، بدون هزینه — فقط قدرت GitHub.
