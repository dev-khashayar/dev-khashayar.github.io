این ابزار چطور کار می‌کنه؟

یه اسکریپت پایتون از طریق GitHub Actions اجرا میشه و ۲۰۰+ کانال تلگرامی رو برای پیدا کردن کانفیگ‌های پروکسی و VPN اسکن می‌کنه. هر کانفیگ با یه اتصال TCP واقعی تست میشه تا latency اندازه‌گیری بشه. کانفیگ‌ها deduplicate میشن، بر اساس trust score رتبه‌بندی میشن و به صورت فایل JSON روی GitHub Pages ذخیره میشن.

مقادیر پینگ از سرور GitHub Actions اندازه‌گیری شدن، نه از اینترنت شما.

هیچ داده‌ای به هیچ سروری ارسال نمیشه. تمام پردازش‌ها به صورت محلی در مرورگر شما انجام میشه.
